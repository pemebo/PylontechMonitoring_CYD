Info

Module data and Cells data exports write one CSV file per module and rotate to the next file when the configured records per file is reached. Running both together keeps the module data and the cells data files of a module side by side. Rows are recorded live and only inside the selected From/To window: From empty starts now, To empty runs until stopped. There is no backfill.

History exports write the battery's datalist response verbatim, without added headers.

Only one export can run at a time.
